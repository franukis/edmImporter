01 / INSTALL

Install the mod

Do not place the application folder on C: or inside the game installation directory. If you encounter permission errors, use Run as administrator.

  1. Close DCS and open F16V-PoBit.exe.
  2. Click Select path and choose the target module's bin folder, as shown in 02 / Link.
  3. Select Core and the DLC you want, then click Install selected.
  4. Confirm the aircraft location and wait for Completed.
02 / LINK

Link

Link is the communication interface with the target module. It is usually located in the game installation directory.

DCS World\Mods\aircraft\F-16I\bin
DCS World\Mods\aircraft\F-16CM\bin

Please test other F16 aircraft mods yourself.

03 / UNINSTALL

Uninstall

Close DCS. Click Disable beside a DLC to remove it, or beside Core to remove the entire mod. Wait for Completed.

Keep the application folder and backups until removal finishes.

04 / UPDATE

Update

  1. Keep Updates checked to check for updates when the application opens.
  2. Select the updates you want and click Download and install.
  3. Wait for completion. The application restarts automatically when its own software is updated.
05 / OPTIONAL DLC

DLC guide

The eight optional components below cover displays, weapons, fuel, the drag chute, cockpit appearance, and HOTAS controls. Select the components you want in the installer. Click Disable beside an installed component to remove it.

CPD, HD Cockpit, and WAR HUD can be selected independently. GBU / SDB weapon controls are also available on the aircraft's native MFDs when CPD is disabled.

CPD

Adds the custom cockpit display, its controls, and matching first-person and external-view models. Switch on CPD, then use the buttons around the display and its page menu to choose a format.

PageUse
HSIMap, waypoints, and route view. HSI shows waypoints 1–24. Use LINK to follow the aircraft's selected waypoint, or leave it off to browse locally.
FLYFlight instruments and the available video view. Use the page's displayed mode and view controls.
TGP / ATPTargeting-pod video and controls. Use the aircraft's existing HOTAS bindings. Assigned, unreleased SDB targets can be shown as TGT markers.
FCR / HSD / HAD / WPNThe corresponding aircraft sensor or weapon format. Use the current on-screen labels.
FLIR / TFRAAQ13 navigation-pod pages. Fit the pod and use its power, mode, and image controls.
SMS weapon panelWeapon selection, power, SDB target assignment, guidance, and release settings. See GBU / SDB.

Controls and picture adjustment

  • Bind power, display buttons, brightness, and the available axes under Pobit → CPD in the aircraft's Controls menu. These CPD actions have no default keyboard assignments.
  • The lower brightness knob controls overall screen brightness. BRT and CON adjust the video or map picture.
  • Press GRAY at L06 to adjust the current picture: L02 / L03 change BRT and R02 / R03 change CON. Press L06 again to return. The SMS panel includes the grayscale reference image.

Disable CPD to restore the corresponding aircraft appearance. The shared weapon functions and native MFD SMS controls remain available.

GBU / SDB

Adds GBU-39/B and GBU-53/B Small Diameter Bombs, BRU-61 racks, and their models and textures. Choose the desired stores in the aircraft loadout, then use the SMS controls on a native MFD or CPD.

  1. Select the weapon and switch its power on. Check the displayed inventory and readiness.
  2. Choose PRE for a planned target or TOO for a target designated during flight.
  3. Use STEP to select a station. In PRE, use ENT to commit the target; in TOO, use the pod designation and TMS target-entry control. Confirm the target was accepted before continuing. CLR clears an assignment.
  4. Choose guidance, HI / LOW flight profile, and the single or paired release setting. Check the release envelope, then use the aircraft's weapon-release control.
SettingMeaning
PRE / TOOHow a target is assigned. This selection is separate from guidance and flight profile.
NA — GBU-53Autonomous terminal acquisition. The acquisition scheme uses LOBL (lock before release) or LOAL (search after release), according to the target-assignment conditions.
LIA — GBU-53Laser-illuminated attack. Match the weapon's laser code to the designator and maintain the required illumination.
HI / LOWFlight-profile selection, independent of PRE / TOO and NA / LIA. LOW has a shorter release envelope; use the current HUD and range indications.
GBU-39Uses its assigned-coordinate attack logic. NA / LIA are GBU-53 settings.

Assigned targets for unreleased weapons can appear as TGT markers on TGP / ATP, up to eight. A failed acquisition does not count as an accepted target. Check the selected weapon and its assignment before release.

CFT/AUX

Combines the conformal fuel tanks, AUX assembly, and drag chute in one component, with their models, textures, and cockpit controls.

CFT fuel and AUX loadout

Choose 3060 lb FUEL for the CFT loadout and AUX for the AUX assembly. The CFT pair supplies its additional fuel inventory. Use the aircraft's fuel indications and existing fuel controls to monitor it.

Drag chute

The chute is included in CFT/AUX; fit AUX in the aircraft loadout to carry it. Open the cockpit chute-switch guard before deploying. Use DEPLOY to deploy the chute and CUT to release it.

ControlBinding
Open / close guardAUX drag chute - GUARD OPEN/CLOSE under Pobit → AUX; assign a key or use the cockpit guard.
DeployAUX drag chute - DEPLOY; default keyboard: left Ctrl + left Alt + left Shift + P.
CutAUX drag chute - CUT; default keyboard: left Ctrl + left Alt + left Shift + O.

The deploy shortcut respects the guard. Releasing the shortcut does not cut the chute; CUT is a separate action. Cutting a deployed chute does not repack it.

AAQ13

Adds the AN/AAQ-13 navigation pod, its textures, and loadout icon. Select AN/AAQ-13 in the aircraft loadout, then use the pod's FLIR and TFR pages.

Check pod power and the displayed operating state. Use the page controls and the aircraft's existing ICP FLIR controls for polarity, gain, level, and image adjustment. CPD also provides FLIR / TFR page selections when installed.

AAQ13 is the navigation-pod component. The targeting-pod video appearance is selected separately through Color TGP.

For detailed operating instructions, refer to the BMS manual.

WAR HUD

Replaces the cockpit HUD's appearance with the WAR HUD frame, optical glass, coating, and matching materials and textures.

Install WAR HUD and enter a new simulator session to view it. Continue using the aircraft's normal HUD controls. It can be selected with or without CPD and HD Cockpit; disabling it restores the corresponding base HUD appearance.

After installation, the HUD's visible area increases by 30%.

HD Cockpit

Provides the optional high-definition cockpit model and textures. Select it for the HD cockpit appearance, then enter a new simulator session.

HD Cockpit is separate from CPD and WAR HUD, so choose those components independently. Disable HD Cockpit to return to the base cockpit appearance.

Color TGP

Enables the optional color presentation for the targeting-pod display. Install it, then open the TGP / ATP view and use the existing pod controls.

It changes the video presentation; it does not add a pod to the aircraft loadout. Disable it to restore the base display appearance.

DMSforA10

Adds A-10-style DMS operation. Use the aircraft's existing HOTAS DMS bindings: short presses cycle display pages, while long presses select the sensor of interest (SOI). The long-press threshold is 0.5 seconds.

Disable DMSforA10 to restore the base DMS scheme.

Custom models and textures: replace the corresponding assets in the component package while retaining their filenames and paths. See Custom component files for applying edited files.

Custom component files

Keep the component identity and file paths in its package description. You can edit the component files without updating their recorded hashes or sizes. Update detection compares component versions only. To apply edited files at the current version, select the component and click Install again.

Installation, updates, and removal accept files you have edited in the component package or the installed module. Original-file backups and interrupted-operation recovery remain available.
